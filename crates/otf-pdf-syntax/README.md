# otf-pdf-syntax

The bottom layer of [otf-pdf](https://github.com/Open-Tech-Foundation/PDF): byte
sources and the PDF file header today; lexer, objects, xref, filters,
decryption and repair as Phase 1 lands.

Most users want the `otf-pdf` facade crate instead. This crate's API is
internal and may change without notice.
