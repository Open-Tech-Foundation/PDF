# otf-pdf-doc

The document layer of [otf-pdf](https://github.com/Open-Tech-Foundation/PDF):
the page tree with inherited attributes, document metadata (Info and XMP),
outlines and attachments. Editing and saving arrive in Phase 2.

Most users want the `otf-pdf` facade crate instead. This crate's API is
internal and may change without notice.
