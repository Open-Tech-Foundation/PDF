# otf-pdf-font

Fonts for [otf-pdf](https://github.com/Open-Tech-Foundation/PDF): simple and
composite fonts, encodings, CMaps, ToUnicode and widths.

Most users want the `otf-pdf` facade crate instead. This crate's API is
internal and may change without notice.

The glyph list, encodings and standard 14 font metrics are generated from
[pdf.js](https://github.com/mozilla/pdf.js) (Copyright Mozilla Foundation,
Apache-2.0).
