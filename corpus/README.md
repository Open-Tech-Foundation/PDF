# Test corpus

| Directory | What | In git |
|---|---|---|
| `malformed/` | Hand-made files, one per repair path or resource limit | Yes, generated by `scripts/generate-malformed-corpus.py` |
| `external/` | pdf.js, PDFBox and veraPDF test files at the commits in `sources.tsv`, plus optional Isartor | No, fetched by `scripts/fetch-corpus.sh` |
| `baseline/` | Known failures per corpus check; may only shrink | Yes |

```sh
scripts/fetch-corpus.sh                       # every source
scripts/fetch-corpus.sh pdfjs                 # one source
ISARTOR_ZIP=~/isartor.zip scripts/fetch-corpus.sh isartor
cargo test --test corpus                      # corpus checks
OTF_PDF_UPDATE_BASELINE=1 cargo test --test corpus   # after fixing failures
```
